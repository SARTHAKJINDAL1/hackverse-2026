# Project Overview

HackVerse 2026 is a modern hackathon registration website designed to provide participants with an engaging and user-friendly experience. The website showcases essential event information including the schedule, prizes, sponsors, and registration details through a clean and responsive interface.

The project focuses on creating a professional frontend experience using HTML, CSS, and JavaScript while ensuring responsiveness, accessibility, and interactive UI elements.

# Features

## Responsive Design

- Fully responsive layout
- Mobile-friendly interface
- Optimized for desktop, tablet, and mobile devices

---

## Dark Mode

Implemented a dark mode toggle that allows users to seamlessly switch between light and dark themes.

---

## Countdown Timer

A live countdown timer dynamically displays the remaining time before the hackathon begins.

---

## Animated Statistics

Statistics in the About section animate when they become visible on the screen using the Intersection Observer API.

---

## Smooth Navigation

- Smooth scrolling
- Active navigation highlighting
- Fixed navigation bar

---

## Interactive Timeline

A clean event timeline displays the complete hackathon schedule in chronological order.

---

## Registration Form

The frontend registration form includes JavaScript validation for:

- Required fields
- Email format
- Phone number
